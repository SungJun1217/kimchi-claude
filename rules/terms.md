# 직역과 음차

영어 용어를 억지로 직역하거나 음차해서 만든, 한국어로 통하지 않는 표기를 모은다.

두 방향의 실패가 함께 들어 있다.

- **과잉 번역** — 정착한 외래어를 억지로 우리말로 바꾸는 것. "캐시"를 "임시 저장소"로.
- **불필요한 음차** — 우리말 용어가 있는데 소리만 옮기는 것. "블라스트 레디우스".

두 번째 줄에 주의한다. 우리말로 풀어쓴 서술문도 실패다. "여파가 미치는 범위"는 "영향 범위"로 줄여야 한다.

| 원어 | 쓰지 말 것 | 쓸 것 | 이유 | 검사 | 순위 |
|---|---|---|---|---|---|
| blast radius | 블라스트 레디우스 | 영향 범위 | 우리말 용어가 있어 음차할 이유가 없다 | 치환 | 핵심 |
| blast radius | 여파가 미치는 범위 | 영향 범위 | 풀어쓰기로 늘어졌다 | 치환 | 핵심 |
| contract | 계약 | 인터페이스 / 규약 | API 문맥의 contract는 계약이 아니다. 법률 문맥일 때만 계약이다 | 프롬프트 | 핵심 |
| cache | 임시 저장소 | 캐시 | 정착한 외래어를 되돌리면 오히려 낯설다 | 치환 | 핵심 |
| commit | 제출 | 커밋 | 정착한 외래어다 | 치환 | 핵심 |
| merge | 합치기 | 머지 | 정착한 외래어다 | 치환 | 보통 |
| thread | 실 | 스레드 | 정착한 외래어다. 한 글자라 문자열 검사는 하지 않는다 | 정규식 | 보통 |
| buffer | 완충 장치 | 버퍼 | 정착한 외래어다 | 치환 | 보통 |
| source of truth | 진실의 원천 | 원본 | 직역하면 뜻이 사라진다 | 치환 | 보통 |
| escape hatch | 이스케이프 해치 | 우회 수단 | 음차가 통하지 않는다 | 치환 | 보통 |
| idempotent | 아이덤포턴트 | 멱등 | 한자어 용어가 이미 통용된다 | 치환 | 보통 |
| invariant | 인베리언트 | 불변식 | 한자어 용어가 이미 통용된다 | 치환 | 보통 |
| ladder | 레더 | 사다리 / 단계 | 음차할 이유가 없다. 문맥에 맞는 우리말을 쓴다 | 정규식 | 보통 |
